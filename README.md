# GoStartup — Mobile-First Landing Page

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
![TailwindCSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)


GoStartup is a high-performance, mobile-first landing page built with HTML and Tailwind CSS. It replicates and customizes key sections of the GoStartup template with a focus on layout precision and responsive "Deployment-First" design logic. The page is fully functional offline using a local Tailwind CLI build.

**Live Demo:** [go-tailwind.preview.uideck.com](https://go-tailwind.preview.uideck.com/) | **Template Source:** [UIdeck GoStartup](https://go-tailwind.preview.uideck.com/)

## Features

- **Mobile-First Design** — All styles written for the smallest screen first, then scaled up using `md:`, `lg:`, and `xl:` prefixes
- **90% Photograph Hero Layout** — Hero image container occupies `w-[90vw]` (90% of viewport width) on mobile devices
- **Highlighted Pricing Card** — The "Basic" pricing plan uses `scale-105` and a `border-blue-600` border to stand out as the most popular option
- **Semantic HTML** — Proper use of `<header>`, `<section>`, `<article>`, and `<footer>` tags throughout
- **Zero Inline Styles** — All styling done exclusively with Tailwind utility classes
- **No External CDN Dependencies** — Can run fully offline with a local Tailwind CSS build
- **Responsive Navigation** — Hamburger menu on mobile, full nav on desktop
- **Back to Top Button** — Appears after scrolling 300px down the page
- **Smooth Scroll** — Section anchors scroll smoothly

## Local Setup

### Requirements
- [VS Code](https://code.visualstudio.com/) with the **Live Server** extension installed
- [Node.js](https://nodejs.org/) (for Tailwind CLI)

### Steps

1. **Clone or download this project**
   ```bash
   git clone https://github.com/your-username/gostartup-landing.git
   cd gostartup-landing
   ```

2. **Open with Live Server**
   - Right-click `index.html` in VS Code
   - Select **"Open with Live Server"**

3. **View in browser**
   - The page will open at `http://127.0.0.1:5500/index.html`

## Offline Setup (No Internet)

> The assignment requires the project to work **without any CDN calls**. Follow these steps to set it up for offline use.

### 1. Install Tailwind CSS via CLI

```bash
npm install -D tailwindcss
npx tailwindcss init
```

### 2. Create your input CSS file

Create a file at `src/input.css` and add:

```css
@tailwind base;
@tailwind components;
@tailwind utilities;
```

### 3. Build the CSS file

```bash
npx tailwindcss -i ./src/input.css -o ./dist/output.css --watch
```

### 4. Update the `<head>` in `index.html`

Replace the CDN script tag:
```html
<!-- Remove this line -->
<script src="https://cdn.tailwindcss.com"></script>

<!-- Add this line instead -->
<link rel="stylesheet" href="./dist/output.css">
```

### 5. Download the images

Download all images from [https://go-tailwind.preview.uideck.com/](https://go-tailwind.preview.uideck.com/) and save them inside the `src/images/` folder matching the folder structure above.

### 6. Update image paths in `index.html`

Replace all remote image URLs like:
```html
src="https://go-tailwind.preview.uideck.com/src/images/hero/image-2.jpg"
```

With local paths like:
```html
src="./src/images/hero/image-2.jpg"
```

### 7. Download and self-host the font (optional)

Download the **Inter** font from [Google Fonts](https://fonts.google.com/specimen/Inter) and serve it locally to remove the Google Fonts dependency.
